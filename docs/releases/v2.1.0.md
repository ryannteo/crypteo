# 2.1.0 release run (v2.1.0)

## Summary

2.1.0 is V2's wrap-up release: commit `87421417044f719bc8b32a5057c7d2bf3461c36b`,
package version 2.1.0. At that commit, CI passed, a fresh clone of GitHub
reproduced the checkout's code identity, a wheel built from the clone ran the
synthetic demo twice outside any checkout with byte-identical output, the
release smoke passed from that wheel, and the release-run script's own tests
passed.

A fresh download of the V1 release range was complete, 1,094 hours per pair, but
no pair reproduced v2.0.0's dataset version. Coinbase had revised historical
prices after v2.0.0's download, including candles in the release window itself
for BTC-USD and ETH-USD. The release-run script refuses to plan on data that is
not v2.0.0's, so the run stopped before any spend. No model was called, and the
Console ledger closed at 0.00 USD. This release therefore contains no live
research run and no performance result.

## What 2.1.0 adds

Since `v2.0.0` (`git log v2.0.0..87421417`), V2's evaluation and its results:

- Research-policy changes decided or pre-registered in an ADR, among them: conditioned
  crossing base rates (ADR-015), a tool budget covering every single-pair tool
  (ADR-016), a critic that tests both cases (ADR-017), planning only candidates
  the baseline would trade (ADR-018), a graded lean (ADR-020) and a peer
  comparison (ADR-025).
- Evaluation trials 7 and 8, the no-`TRADE` diagnostic, the baseline-strategy and
  bar-length studies, the trading-logic exploration and both ranking trials.
- The local read-only run viewer, `crypteo_viewer`
  ([ADR-022](../decisions/ADR-022-local-run-viewer.md)), and the one-command
  synthetic demo, `crypteo_demo`.

The [V2 summary](../evaluations/v2-summary.md) records what these found, their
spend and what stays open.

## The dataset revision

The script then downloaded Coinbase Exchange hourly candles for BTC-USD, ETH-USD
and SOL-USD over the V1 release range [2026-09-01T00:00:00Z,
2026-10-16T14:00:00Z), the range v2.0.0 downloaded. Each pair returned 1,094
candles with no missing hours, but every dataset version differs from v2.0.0's,
and the script exited 1 (`run-handoff/step2-4-download.txt`):

| BTC-USD | `sha256:a94b6839f847c518459db5b6a74de0a35df6dd6773e8f0c64f5e41ac6caf33ab` | `sha256:67ecd6ed5b8b32ee6c943cb87ce9788a476cbefafc12723d05ca233ae4e90a21` |

| SOL-USD | `sha256:5905cba200bef520e9ce28eb1bd2284e02f7bbc60bfba37b3012006c47d32639` | `sha256:372fb4a64a24301c393ac07dcdb5b7c3f7e1b1d76e104659f4448367f6fbbb62` |

The new acquisition IDs are `sha256:7f929f4248bc…` (BTC-USD), `sha256:6f242b40bb17…`
(ETH-USD) and `sha256:b10cdaa30f81…` (SOL-USD), recorded in full in

A read-only comparison with v2.0.0's stored data (`~/crypteo-eval/data-release`,
created 2026-10-21T10:59:27Z) found the same 1,094 open times per pair. The
manifests differ only in creation time and dataset version, and volume and

low and close prices (`run-handoff/dataset-comparison.txt`):

| Pair | Rows changed (of 1,094) | Fields changed | Range of changed rows (open time, UTC) | Largest relative change | Changed rows on 2026-10-15 and 10-16 |
|---|---|---|---|---|---|
| BTC-USD | 298 | open 132, high 116, low 116, close 47 | 2026-09-13 12:00 to 2026-10-16 13:00 | 1.40e-03 (low) | 22 |
| ETH-USD | 298 | open 153, low 125, high 104, close 29 | 2026-09-26 01:00 to 2026-10-16 13:00 | 1.26e-03 (low) | 25 |
| SOL-USD | 116 | open 67, low 31, high 22, close 15 | 2026-09-01 01:00 to 2026-09-13 11:00 | 3.27e-03 (high) | 0 |

So Coinbase revised historical prices after v2.0.0's download. For BTC-USD and
ETH-USD the revisions reach the release window's own candles: v2.0.0 researched
BTC-USD at 2026-10-15T13:00:00Z, with ETH-USD and SOL-USD bound in its trader-led
runs ([v2.0.0](v2.0.0.md#what-was-run)). A run on this download would not research
the input v2.0.0 did.

What follows: a fresh download of a range is not guaranteed to reproduce an
earlier dataset version, even with no missing hours. A dataset version identifies
canonical content, not a request
([data pipeline](../data-pipeline.md#canonical-dataset-identity)), and the stored
dataset is what makes a run reproducible. v2.0.0's run cannot be repeated on
freshly downloaded data.

## No model was called

`release_run.py` refuses to plan on datasets that are not v2.0.0's, by design:
its loader exits unless each recorded dataset is v2.0.0's. Its download step
ended with "the download does not reproduce v2.0.0's datasets; stop and report
before any spend" (`run-handoff/step2-4-download.txt`). The owner then decided
not to run `plan`, `report`, `reproduce` or `identity`, and neither
`run-opportunity` nor `run-trader` ran after the download. The one earlier
`run-trader` attempt was refused before any request (see
[Found during the release](#found-during-the-release)). No request reached a
model. The Console balance was 6.44 USD at the start and 6.44 USD at the end, so
the ledger closed at 0.00 USD (`balances.json`, `run-handoff/checks.txt`).

No live run replaced it. In the `crypteo` package, the release commit differs
from ranking trial 2's run commit `ee348e24f90dd50d28d19076f86d8be53a475e44`
only in its version strings: the package version in `pyproject.toml` and the
Coinbase User-Agent in `src/crypteo/coinbase.py`. The other two of the four
version strings are in `tests/release_smoke.py` and `tests/test_package.py`.
Everything else since that commit is the demo package `crypteo_demo`, its tests,
CI and documentation (`git diff ee348e2 87421417`). Ranking trial 2 ran this
research policy live on `claude-opus-5-5` at effort `high`
([ranking trial 2](../evaluations/v2-ranking-trial-2.md#what-was-run)). That trial
is its own record and is not part of this release run.

## Limitations

- This release made no live model run. Its checks show the release commit builds,
  installs, reproduces its code identity and runs deterministically; they say
  nothing about research quality or trading skill.
- v2.0.0's run cannot be repeated on freshly downloaded data, because Coinbase
  has revised candles in its range. Repeating it needs v2.0.0's stored
  datasets.
- The comparison covers the V1 release range only. It shows that Coinbase revised
  these candles between 2026-10-21 and 2026-11-26; it does not say how often or
  how far back Coinbase revises.
- The CI result was read from the GitHub Actions API by the owner, not captured
  by the release-run session.
- The release-run script was not independently reviewed (part 1's
  `handoff/findings.md`). None of its commands made a model request.
- Licensed raw Coinbase data is not redistributed.
